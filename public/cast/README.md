# OTT Cast / Face Roster Library

Upload your actor/actress face images here!

### Supported Formats
* `.jpg`, `.jpeg`, `.png`, `.webp`

### How It Works:
1. Place up to 10 actor face photos in this folder (`public/cast/`).
2. Examples:
   - `byomkesh.jpg`
   - `feluda.jpg`
   - `anirban_bhattacharya.jpg`
   - `subhashree.jpg`
   - `actor_1.jpg`
3. The dashboard UI will automatically detect all photos and display them as clickable star avatars.
4. When selected, the generator conditions the master poster visual on that actor's look, facial structure, and persona.
